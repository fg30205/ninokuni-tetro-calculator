# 二之國 Tetro 拼圖計算器

瀏覽器端的 9×9 Tetro 謎題排列計算器，內建 94 個現有謎題。

## 資料

- `dist/data/puzzles.json`：版本化謎題資料；每個謎題包含中韓文名稱、9 列二進位遮罩與有效格數。
- `dist/data/pieces.json`：固定七種 Tetromino 與能力對應。
- `tools/extract-presets.mjs`：從原計算器另存 HTML 重新擷取謎題資料，並驗證數量和格數。

## 新增官方謎題

在 `puzzles.json` 的 `puzzles` 陣列追加一筆資料；`rows` 必須有 9 列，每列正好 9 個 `0/1`，且有效格數須為 4 的倍數。再同步更新瀏覽器用的 `puzzles.js`。

## 固定能力方塊

| 方塊 | 能力 |
|---|---|
| O | 攻擊 |
| I | 防禦 |
| T | 體力 |
| L | 迴避 |
| J | 命中 |
| S | 爆擊抵抗 |
| Z | 爆擊 |

方塊僅允許旋轉，不允許鏡像翻面。

計算時不限制方塊持有數量。方案預設依攻擊、防禦、生命、爆擊、命中、迴避、爆擊抵抗排序；使用者也可依點擊順序自訂多層排序優先級。

搜尋會依使用者的第一優先能力調整方塊嘗試順序，並在完整搜尋過程中持續保留排序最佳的 2,000 筆結果，不會因較早找到 2,000 個普通方案而停止。

相同的七種能力方塊數量視為同一個方案；即使棋盤擺法不同，也只保留一個代表布局。

計算模式預設為「快速排序」；切換「進階限制」後，可為每種能力設定最低與最高數量，再依排序優先級排列符合條件的方案。
